O nás

Studio s vášní pro detail

Nail Studio Ellie vzniklo v roce 2019 s jedním cílem — dopřát každé zákaznici péči, na kterou si vzpomene. Pracujeme výhradně s certifikovanými materiály a průběžně se vzděláváme v nejnovějších trendech.

Každý set nehtů je pro nás malé umělecké dílo. Proto si dáváme čas, abychom docílili dokonalého výsledku, který vydá za tisíc slov.

Naše služby

Vyberte si z naší nabídky profesionálních nehtových služeb. Všechny ceny jsou konečné, bez skrytých poplatků.

Gelové nehty

Krásné a odolné gelové nehty v libovolné délce a tvaru. Výdrž 3–4 týdny, dokonalý výsledek pokaždé.

od 650 Kč / set
Manikúra

Klasická manikúra s péčí o kutikuly, pilování do požadovaného tvaru a lakování dle výběru.

od 350 Kč / návštěva
Pedikúra

Kompletní péče o nohy a nehty na nohou, včetně peelingu, hydratace a lakování.

od 450 Kč / návštěva
Nail art

Kreativní zdobení nehtů — florální motivy, geometrie, ombre, chrome a další trendy vzory.

od 150 Kč / nehet
Doplnění

Profesionální doplnění odrostlých gelových nehtů. Doporučujeme každé 3 týdny.

od 500 Kč / set
Prodloužení

Prodloužení nehtů tipy nebo formičkami do požadované délky, tvaru a povrchové úpravy.

od 750 Kč / set
